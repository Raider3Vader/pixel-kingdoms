Controls

Left click / drag
Select units
Double click
All of that type on screen
Right click
Move, gather, build or attack
Shift + click
Add to selection; place several buildings
Shift + right click
Queue orders (waypoints, tree then sheep)
Z X C V B N, F
Commands; F: next build page
Double click building
Select all of that kind; train in each
Right click, building
Rally point; villagers repair it; troops enter towers
W A S D / arrows
Move the camera (or screen edge)
Mouse wheel
Zoom
H
Town Center
Q
Next idle villager
Ctrl + 1-9
Save a group; 1-9 picks it; Shift + 1-9 adds it
Space
Jump to attack or selection
M / Esc / Delete
Mute / pause / destroy selected

Spears beat horses. Armor stops arrows. A gate placed on a wall swaps in. Destroy their Town Center to win.
